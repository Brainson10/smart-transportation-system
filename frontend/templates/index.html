Platform Overview

The Smart Transportation System is an AI-enabled decision-support platform designed to enhance road safety planning and campus vehicle access management. The system follows privacy-by-design principles and supports ethical, explainable AI.

System Modules

Authority / Administration System

Utilizes historical accident data and road geometry parameters to predict accident hotspots and support safety planning.

Gate Security System

Performs real-time vehicle verification using ANPR, confidence assessment, and institutional pass validation.

Operational Workflow

  1. Video and sensor data are captured from deployed cameras.
  2. AI models analyze risk levels and vehicle authenticity.
  3. Explainable outputs support authority planning decisions.
  4. Gate personnel receive privacy-preserving entry alerts.
